# Implementation provenance

Version 1.1.0 replaces the previous encoder with a specification-based signal planner and event-timed PCM synthesiser. The factual protocol inputs, references and explicit application choices are recorded in [tape-format.md](tape-format.md).

The earlier converter source, its licence files, its source-level regression oracle and the associated build/credits dependencies have been removed from the current tree. The current app, test suite and release scripts do not require that converter.

The earlier implementation had already been examined during development. This work is therefore described as a specification-based rewrite, not an isolated clean-room process or a legal opinion about the effect of prior exposure.

This repository starts at v1.1.0. Earlier history and releases are retained separately in a private archive.

The icon's relationship to Sharp's historical ship emblem is separate from tape-encoder provenance. See [the icon notes](../Assets/README.md) and [NOTICES.txt](../NOTICES.txt).
